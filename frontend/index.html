Deployment Guide

1
Verify your sender email in AWS SES

Go to AWS Console → SES → Verified Identities → Create Identity

2
Install AWS SAM CLI npm install -g aws-sam-local
3
Install Lambda dependencies cd lambda && npm install
4
Build and deploy with SAM sam build && sam deploy --guided
5
Copy the API Gateway URL from SAM output and paste it above

The URL looks like: https://xxxx.execute-api.us-east-1.amazonaws.com/prod/send-emails
